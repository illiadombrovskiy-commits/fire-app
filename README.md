# В Слове

**В Слове — приложение для ежедневного чтения Библии, духовного общения и взаимного воодушевления.**

Цель проекта — помочь читателям регулярно пребывать в Слове Божьем, следовать выбранному расписанию и поддерживать друг друга.

## Возможности

- Чтение Библии по готовым и индивидуальным расписаниям, ссылки на Восстановительный перевод.
- Отметки прочитанного, огонёк дня, серии чтения, статистика и награды.
- Вопросы по прочитанному.
- Совместное чтение, жизненные группы и челленджи.
- Друзья, приглашения и воодушевления.
- Глобус читателей, отображающий их главное расписание и активность.
- Вход через Google, локальное хранение и облачная синхронизация прогресса.
- Установка веб-приложения на главный экран телефона.

## Архитектура

Приложение построено на HTML, CSS и JavaScript без обязательного этапа сборки. Firebase используется для авторизации и социальных функций.

| Файл или каталог | Назначение |
|---|---|
| `index.html` | Разметка и подключение модулей |
| `src/` | Расписания, прогресс, состояние, визуальные и социальные модули |
| `src/progress-visual.js` | Основные изображения и эффекты огонька, включая глобус |
| `styles/` | Стили интерфейса и анимации |
| `src/auth.js` | Авторизация и интеграция социальных функций |
| `src/globe.js` | Глобус читателей |
| `src/data.js` | Данные для чтения |
| `firestore.rules` | Правила доступа к базе |
| `manifest.webmanifest`, `sw.js` | Установка приложения и уведомления |
| `tests/` | Автоматические проверки |

Подробности: [архитектура проекта](docs/ARCHITECTURE.md).

## Запуск и тестирование

Для локальной разработки запустите из корня репозитория:

```sh
python3 -m http.server 8000
```

Откройте http://localhost:8000. Для облачных функций необходим настроенный Firebase и разрешённый домен авторизации.

```sh
python3 tests/run_browser.py
python3 tests/test_remind.py
node tests/social.mjs
```

Браузерным тестам нужен Chrome или Chromium; путь можно задать через CHROME_BIN. Проверки правил Firestore выполняются в изолированном Firebase Emulator. Автоматические проверки описаны в [.github/workflows/modular-regression.yml](.github/workflows/modular-regression.yml).

## Развёртывание и безопасность

Приложение можно публиковать через GitHub Pages или Firebase Hosting. Для облачных функций нужны Firebase Authentication (Google), Firestore, корректная конфигурация в `firebase-config.js` и согласованные правила доступа из `firestore.rules`. Не публикуйте приватные ключи или данные пользователей. Изменения схемы хранения и правил следует отдельно проверять перед выпуском.

## Глобус читателей

Книги Библии представлены территориями на глобусе. Положение читателя определяется главным расписанием; огонёк показывает активность чтения. Пользователь может скрыть себя с глобуса. 

## Развитие проекта

Приоритеты — удобство ежедневного чтения, сохранность прогресса, доступность интерфейса и взаимное воодушевление читателей. Изменения должны сохранять совместимость существующих расписаний и пользовательских данных.
