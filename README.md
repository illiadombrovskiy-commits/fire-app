# Огонёк — чтение Библии каждый день

Приложение для ежедневного чтения Восстановительного перевода по плану «15 минут в день» (52 недели). Каждый день читается один отрывок из Нового Завета и один из Ветхого. В приложении:

- огоньки и серии дней, отдельно для каждого завета и общий;
- заморозки серии;
- вопросы по тексту и награды;
- расписание на год и график опережения.

## Как выложить на GitHub (бесплатно, около 10 минут)

1. Зарегистрируйтесь на https://github.com и войдите.
2. Нажмите **«+» → New repository**. Название, например, `ogonek`, выберите **Public** и нажмите **Create repository**.
3. Распакуйте скачанный архив на компьютере.
4. На странице нового репозитория нажмите ссылку **uploading an existing file**. Перетащите в окно **все файлы из распакованной папки** (не сам архив), затем нажмите **Commit changes**.
   - Файл `.nojekyll` скрытый. Если он не перетащился, ничего страшного, сайт заработает и без него.
5. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Source: Deploy from a branch**, ветку **main** и папку **/ (root)**, нажмите **Save**.
6. Через 1–2 минуты сайт будет доступен по адресу:
   `https://ВАШ-ЛОГИН.github.io/ogonek/`

Этот адрес открывается в любом браузере. На телефоне его можно добавить на главный экран («Поделиться → На экран Домой» или «Установить приложение»), и он будет выглядеть как приложение.

## Где хранится прогресс

Сразу после загрузки сайт работает **без входа**: прогресс каждого человека хранится в его браузере.

Чтобы включить **вход по номеру телефона** и хранение прогресса на сервере:

1. Создайте проект на https://console.firebase.google.com и добавьте веб-приложение (значок `</>`).
2. Скопируйте настройки в файл `firebase-config.js`. На GitHub его можно отредактировать прямо в браузере, нажав на карандаш.
3. В Firebase: **Authentication → Sign-in method → Phone** — включите.
4. **Authentication → Settings → SMS region policy** — разрешите Россию и другие нужные страны.
5. **Authentication → Settings → Authorized domains** — добавьте `ВАШ-ЛОГИН.github.io`.
6. **Firestore Database** — создайте базу данных. На вкладке **Rules** вставьте содержимое файла `firestore.rules` и опубликуйте.

Настоящие СМС Firebase отправляет только на платном тарифе **Blaze**. Для проверки можно бесплатно добавить тестовые номера в настройках входа по телефону.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Само приложение: план, огоньки, вопросы, награды |
| `auth.js` | Вход по телефону и сохранение прогресса в Firebase |
| `firebase-config.js` | Настройки вашего проекта Firebase |
| `firestore.rules` | Правила базы: каждый видит только свой прогресс |
| `manifest.webmanifest`, `icon-*.png` | Значок и установка на телефон |
| `firebase.json` | Нужен, только если публиковать через Firebase Hosting вместо GitHub |

## Ссылки на Библию

Отрывки открываются на https://bible.recoveryversion.ru с нужного стиха, например `…/matt/1/1`. Коды книг собраны в таблице `SLUG` в файле `index.html`. Если какая-то книга не открывается, поправьте её код там.
