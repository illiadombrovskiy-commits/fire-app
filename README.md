# Огонёк — чтение Библии каждый день

Приложение для ежедневного чтения Восстановительного перевода по плану «15 минут в день» (52 недели). Каждый день читается один отрывок из Нового Завета и один из Ветхого. В приложении:

- огоньки и серии дней, отдельно для каждого завета и общий;
- заморозки серии;
- вопросы по тексту и награды;
- расписание на год и график опережения.

## Как выложить на GitHub (бесплатно, около 10 минут)

1. Зарегистрируйтесь на https://github.com и войдите.
2. Нажмите **«+» → New repository**. Название, например, `ogonek`, выберите **Public** и нажмите **Create repository**.
3. Распакуйте скачанный архив на компьютере.
4. На странице нового репозитория нажмите ссылку **uploading an existing file**. Перетащите в окно **все файлы из распакованной папки** (не сам архив), затем нажмите **Commit changes**.
   - Файл `.nojekyll` скрытый. Если он не перетащился, ничего страшного, сайт заработает и без него.
5. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Source: Deploy from a branch**, ветку **main** и папку **/ (root)**, нажмите **Save**.
6. Через 1–2 минуты сайт будет доступен по адресу:
   `https://ВАШ-ЛОГИН.github.io/ogonek/`

Этот адрес открывается в любом браузере. На телефоне его можно добавить на главный экран («Поделиться → На экран Домой» или «Установить приложение»), и он будет выглядеть как приложение.

## Вход через Google и друзья

Сразу после загрузки сайт работает **без входа**: прогресс хранится только в браузере, друзей нет. Чтобы включить вход через Google и раздел «Друзья», нужен бесплатный проект Firebase. Это делается один раз, около 10 минут.

1. Откройте https://console.firebase.google.com, нажмите **Создать проект** (например, `fire-app`). Google Analytics можно отключить.
2. На главной странице проекта нажмите значок **`</>`** (веб-приложение), введите название и нажмите **Зарегистрировать**. Появится блок `const firebaseConfig = { ... }`.
3. Откройте на GitHub файл `firebase-config.js`, нажмите на **карандаш** (Edit) и замените значения на свои: `apiKey`, `authDomain`, `projectId`, `storageBucket`, `messagingSenderId`, `appId`. Нажмите **Commit changes**.
4. В Firebase: **Build → Authentication → Get started → Sign-in method → Google** → включите → укажите свою почту → **Save**.
5. **Authentication → Settings → Authorized domains → Add domain** → впишите `ВАШ-ЛОГИН.github.io`.
6. **Build → Firestore Database → Create database** → выберите регион (например, `eur3`) → режим **production**.
7. В Firestore откройте вкладку **Rules**, удалите всё и вставьте содержимое файла `firestore.rules` из этого репозитория → **Publish**.

После этого на сайте появится кнопка «Войти через Google» и раздел «Друзья».

### Как добавить друга

- У каждого есть свой код из 6 знаков, например `K7Q2MX`. Он показан в разделе «Друзья».
- Нажмите **«Скопировать приглашение»** и отправьте другу. По ссылке из приглашения друг добавится автоматически после входа.
- Можно и вручную: в поле «Код, почта или ID друга» введите код друга из 6 знаков, его почту Google (если он уже входил в Огонёк) или его ID и нажмите «Добавить».
- Дружба по заявке: когда вы вводите код друга, ему приходит заявка, а вы становитесь его подписчиком. Друг нажимает «Принять» — и вы друзья. Если он отклонит заявку, вы останетесь подписчиком. На тропинке и в «Воодушевить» участвуют только друзья.
- Удалить друга можно кнопкой «Удалить» (нажать два раза).

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Само приложение: план, огоньки, вопросы, награды |
| `auth.js` | Вход через Google, сохранение прогресса и друзья (Firebase) |
| `firebase-config.js` | Настройки вашего проекта Firebase |
| `globe.js` | Глобус читателей: планета, где книги Библии — страны на материках, а читатели стоят на той книге, которую читают |
| `sw.js` | Показывает уведомления, когда друг вас воодушевляет |
| `firestore.rules` | Правила базы: свой прогресс видите только вы, а профиль — только ваши друзья |
| `manifest.webmanifest`, `icon-*.png` | Значок и установка на телефон |
| `firebase.json` | Нужен, только если публиковать через Firebase Hosting вместо GitHub |

## Ссылки на Библию

Отрывки открываются на https://bible.recoveryversion.ru с нужного стиха, например `…/matt/1/1`. Коды книг собраны в таблице `SLUG` в файле `index.html`. Если какая-то книга не открывается, поправьте её код там.

## Глобус читателей

Вкладка «Друзья» → «Глобус читателей». Планета похожа на Землю, и каждый материк разделён на страны-книги по порядку:

- Северная Америка — Пятикнижие и исторические книги;
- Южная Америка — поэтические книги и большие пророки;
- Африка — малые пророки;
- Европа — Евангелия и Деяния;
- Азия — послания Павла;
- Австралия — общие послания и Откровение.

Человек стоит на той книге, которую читает сейчас. Если он сегодня уже читал, над ним горит огонёк и подсвечивает землю вокруг. На глобусе видны все читатели (до 1000 человек). Человек появляется там, как только откроет новую версию Огонька; ваши друзья и подписки видны сразу — их данные берутся из профилей. Кнопка «Новые» по очереди показывает тех, кто ещё не у вас в друзьях (сначала тех, у кого вообще нет друзей),. Любому из них можно сразу отправить заявку в друзья.

Кто читает оба Завета, стоит сразу на двух книгах (например, на Матфее и на Бытии), и на каждой свой огонёк: он горит, если этот отрывок прочитан сегодня. Данные для глобуса лежат в коллекции `globe/{uid}`: имя, фото, номер книги, отрывки, серия и отметка, читал ли человек сегодня. Каждый может скрыть себя кнопкой «Скрыть меня» внизу глобуса; тогда его документ удаляется. После обновления `firestore.rules` нажмите Publish в Firebase.

## Огонёк дня и серия

- Огонёк на главной горит полностью, когда прочитаны все отрывки дня. Если в расписании только один Завет, он сразу горит полностью.
- Пропустили вчера — прочитайте вчерашний отрывок («Догнать» на главной), и серия вернётся сама: вчерашний день станет заморозкой. Для пропуска в 2–3 дня остаётся кнопка «Вернуть серию» (раз в 30 дней).
